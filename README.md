# EY Day 1 - HTML Practice Project

## About

This project was created as part of EY Day 1 to learn and practice the fundamentals of HTML (HyperText Markup Language).

The project contains different HTML pages demonstrating basic HTML elements, forms, multimedia, page layouts, tables, lists, links, and a simple personal portfolio.

## Technologies Used

- HTML5
- Git
- GitHub
- Visual Studio Code

## Project Files

- `index.html` - Basic HTML elements, headings, paragraphs, lists, images, links, and tables
- `form.html` - Student registration form
- `multimedia.html` - Audio, video, and embedded content
- `portfolio.html` - Simple personal portfolio
- `layout.html` - Basic webpage layout using semantic HTML elements
- `README.md` - Project documentation

## HTML Concepts Covered

- Heading tags
- Paragraphs
- Text formatting
- Lists
- Nested lists
- Tables
- Images
- Hyperlinks
- Forms
- Input elements
- Audio and video
- iframe
- Header and footer
- Navigation
- Section
- Main content
- Aside
- Semantic HTML

## Student Registration Form

The registration form includes:

- Full Name
- Email
- Phone Number
- Gender
- Date of Birth
- Course
- Skills
- Address
- Resume Upload
- Password
- Submit and Reset buttons


## Purpose

The purpose of this project is to understand the basic structure and different elements of HTML and to create simple webpages using HTML.

## How to Run

1. Open the project in Visual Studio Code.
2. Open any `.html` file.
3. Run the file in a web browser.
4. You can also use the Live Server extension in VS Code.
